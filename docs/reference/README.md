# Reference Documentation

This directory preserves evidence from the legacy product and the active disposable
reference runtime. Reference documents are not requirements or target architecture
decisions. The canonical Phase 0 documentation is indexed in `../README.md`.

| Directory | Meaning |
| --- | --- |
| `legacy/` | Historical product, UX, and implementation discovery |
| `runtime/` | Current reference-runtime deployment and migration procedures |
| `superseded/` | Replaced proposals retained for decision history |

Do not implement from a reference document unless the canonical PRD, SRS, or a
current ADR explicitly links it as approved evidence.
